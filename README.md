# syspeek 🔍

A simple, fast, and lightweight system information tool written entirely in Bash. 

`syspeek` gathers the most important details about your Linux system (like OS, Kernel, CPU, RAM, Disk, and Network) and displays them in a clean, easy-to-read terminal output.

## ✨ Features
* **No dependencies:** Uses standard Linux tools (`grep`, `awk`, `free`, `df`).
* **Fast:** Written in pure Bash, so it runs instantly.
* **Clean UI:** Outputs beautifully formatted text using basic tab spacing.
